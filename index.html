🏛️ Academic Project Architecture: Serverless API vs. Native Streamlit

This portal demonstrates a dual deployment architecture designed for academic evaluation:

[Vercel Serverless Function: api/index.py] <--- Python 3.10+ (@vercel/python) ├── Pure HTTP JSON REST Endpoints: GET /api/index?action=indicators | news | interpret ├── Serverless execution ceiling: < 10s execution | Stateless | Scalable on-demand └── Serves static HTML/JS frontend from root [Streamlit Cloud Native App: app.py] <--- Python Stateful Daemon (Tornado) ├── Persistent bi-directional WebSocket connection (ws://) ├── Real-time Plotly interactive charts & reactive parameter sliders └── Official platform specified in GEMINI.md project instructions
