Analytical Synthesis • Module D

2. Evidence-Based Economic Interpretation

Structured deterministic synthesis matching verified indicator shifts with news topics extracted via transparent NLP rules.

Academic Notice & Analytical Limitations (Non-Causal Rule)
1. Timing Discrepancy: Official macroeconomic indicators (World Bank) are published annually with collection lags, whereas news headlines reflect immediate weekly sentiment.
2. Correlation ≠ Causation: Co-occurrence between a news topic and an indicator shift illustrates potential economic transmission mechanisms, but does not prove direct causation.
3. Deterministic Explainability: All conclusions are generated via deterministic Python templates and keyword matching, ensuring complete auditable transparency without generative hallucination.

Technical Specification: Dual Deployment Architecture & Governance

View Engineering Notes ↓

This repository supports a dual-runtime architecture designed to satisfy both public serverless edge delivery and stateful academic evaluation without code duplication:

Runtime Dimension Vercel Serverless Function (Production Edge) Streamlit Cloud Native (Specification Benchmark)
Entry Point api/index.py (@vercel/python runtime) app.py (Tornado Web Framework)
Protocol Stateless HTTP REST (/api?action=...) Stateful Bi-directional WebSockets (ws://)
Frontend Delivery Standard Semantic HTML5, CSS Tokens, Chart.js Reactive Streamlit Component Tree with Plotly
Caching Strategy In-memory process cache per execution instance @st.cache_data(ttl=3600) memory cache
Target Audience Instant global web browsing, lightweight mobile client Interactive classroom demonstration & code inspection
Security Notice: No external private keys are exposed in client-side bundles. World Bank queries use open unauthenticated REST endpoints; News queries fall back to validated public feeds or curated development fallbacks.

The Economic Interpreter

An academic data science capstone project developed by Aryan Rane, Third-Year BSc Data Science student.

Designed to improve economic literacy by systematically connecting empirical macroeconomic indicator shifts with contemporary news coverage using deterministic Natural Language Processing.
